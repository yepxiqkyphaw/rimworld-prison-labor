## Overview

Prison Labor lets colonists assign captured prisoners to work details, earn trust through labor, and eventually join the colony, adding a new social dynamic and a steady workforce pipeline.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Prison Labor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Work Assignment** | Assign prisoners to hauling, farming, or crafting work details |
| **Trust System** | Labor and positive interactions build trust toward recruitment |
| **Suppression Mechanic** | Guards maintain control; low suppression triggers escape attempts |
| **Skill Learning** | Prisoners improve skills during labor, arriving as better recruits |
